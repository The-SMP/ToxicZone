# ToxicZone

Paper 毒圈插件，支援 Minecraft 1.21.11 至 26.3。

## 安裝

1. 將 `ToxicZone.jar` 放進伺服器的 `plugins` 資料夾。
2. 啟動伺服器，插件會建立 `config.yml` 和 `messages.yml`。
3. 使用遊戲內指令或設定檔調整毒圈。

Paper 26.1 以上版本需要 Java 25 執行。

## 使用方式

輸入 `/tz` 開啟控制面板。點左上角的箱子可開啟場地清單、建立場地或切換編輯對象。面板會顯示場地名稱，起始半徑與縮圈時間各有兩種調整幅度。面板使用左鍵操作，可設定中心、半徑、縮圈時間、傷害與傷害間隔，也可開始或停止縮圈。

設定區域時，輸入 `/tz wand` 取得胡蘿蔔釣竿。左鍵選第一個角，右鍵選第二個角。毒圈尚未開始時，選區邊緣會以粒子顯示。

只有位於場地外框內、且在圓形安全區外的玩家會受到傷害。毒圈到達最小半徑後會自動停止。死亡玩家在該場不會再受到毒圈傷害；管理員開始新一場時會重設淘汰狀態。

同一個世界可以有多個場地。用 `/tz arena create <名稱>` 建立並選取場地，再用 `/tz wand` 選兩個角設定外框。用 `/tz arena use <名稱>` 切換場地，`/tz arena list` 查看清單。既有場地的名稱是 `default`。同時運作的場地外框不能重疊。

縮圈以保存的開始時間計算，重載或重啟會接續進度，停機時間也會計入。舊版沒有保存開始時間，更新時仍在進行的舊場次會停止，請重新開始一場。

## 指令

| 指令 | 說明 |
| --- | --- |
| `/tz` | 開啟控制面板 |
| `/tz status` | 查看毒圈狀態 |
| `/tz center` | 將中心設在目前位置 |
| `/tz center <世界> <x> <z>` | 指定毒圈中心 |
| `/tz wand` | 取得區域選取釣竿 |
| `/tz radius <起始半徑> [最小半徑]` | 設定毒圈半徑 |
| `/tz time <秒數>` | 設定縮圈時間 |
| `/tz damage <傷害值> [間隔秒數]` | 設定傷害與間隔 |
| `/tz start` | 開始縮圈 |
| `/tz stop` | 停止縮圈 |
| `/tz reload` | 重新載入設定 |
| `/tz version` | 檢查插件版本 |

除版本檢查外，管理指令限 OP 或具備 `auroratoxiczone.admin` 權限的玩家使用。版本檢查權限為 `auroratoxiczone.version`。

## 預設值

- 每秒造成 3 點傷害，相當於 1.5 格紅心。
- 玩家與毒圈中心的水平距離超出目前半徑時會受傷。
- 邊界以亮綠色粒子顯示。
- 設定可透過控制面板或 `plugins/ToxicZone/config.yml` 調整。

## 建置

需要 Maven 和 Java 21。於專案目錄執行：

```sh
mvn package
```

輸出檔案位於 `target/toxic-zone-1.2.0.jar`。
